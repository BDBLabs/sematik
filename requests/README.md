# Approval / Review Requests

When sematik needs a human decision or review (spec §15 questions,
mapping approvals, major architectural confirmations), a timestamped
markdown file is dropped in this folder. The owner watches this directory
and replies by editing the `Decision:` field.

Each request names:
- the affected concept/mapping,
- candidate interpretations,
- affected record counts,
- evidence,
- downstream consequences,
- the specific question(s) to answer.
